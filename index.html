ABOUT TOOLFORGE

Simple tools without unnecessary steps

ToolForge is a small collection of practical online utilities built for common tasks. The goal is straightforward: open the page, choose the tool you need, do the task, and move on. The site does not require an account for the core browser-based tools.

For supported file tools, processing happens in your browser. That means an image selected for compression or a PDF selected for merging or splitting is handled on your device rather than uploaded to a ToolForge file server. The currency converter is different because it needs an external exchange-rate service to retrieve current rates.

How to use ToolForge

  1. Select a tool from the directory or navigation bar.
  2. Enter your value, text or file according to the tool.
  3. Review the result and download the generated file when available.

FAQ

Frequently asked questions

Are the tools free to use?

Yes. The current ToolForge core tools are provided for free and do not require an account.

Are my images and PDFs uploaded?

The image compressor, PDF merge and PDF split tools process selected files in the browser. See the Privacy Policy for the current data-handling details.

Does the currency converter use live rates?

It requests a current exchange rate from the external Frankfurter service when you press Convert. Rates can change and should be treated as informational.

Can I use ToolForge on a phone?

Yes. The layout is responsive and the tools are designed to work on modern desktop and mobile browsers.

How does ToolForge make money?

ToolForge is being prepared for ethical, policy-compliant monetization such as advertising. Monetization will not change the basic purpose of the tools.
