# ToolForge launch checklist

## Current build
- `index.html` — main tool suite
- `privacy.html` — privacy disclosures
- `about.html` — project/about information
- `terms.html` — terms of use
- `contact.html` — contact/feedback page placeholder until a real support email is configured
- `site-pages.css` — shared styling for informational pages
- `site.webmanifest` — installable web-app metadata
- `robots.txt` — crawler rules
- `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` — icons
- `og-image.png` — social preview image

## Before public launch
1. Choose the final public domain/host.
2. Add a real support/contact email to `contact.html` and update the Privacy Policy/Terms if needed.
3. Replace relative Open Graph image URLs with the final absolute URL if your social preview tool requires it.
4. Create `sitemap.xml` using the final domain.
5. Test every tool on desktop and mobile, especially image/PDF downloads.
6. Test the currency converter from the live HTTPS site.
7. Check every navigation link and informational page.
8. Add analytics only if you actually need it and update the privacy disclosures accordingly.
9. Only after the site has real, useful content and stable pages should you apply for advertising monetization.
10. When advertising is approved, add the provider's official code and publisher information. Do not publish placeholder ad IDs.

## Monetization note
Advertising approval is not guaranteed. Google says AdSense applicants must be 18 or older, have original content, comply with policies, and have a site with useful, clear navigation. If the site owner is under 18, Google says a parent or guardian may sign up using their own Google Account; payments go to the adult responsible for that account.
